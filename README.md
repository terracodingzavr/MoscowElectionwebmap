Проект Выборы Москвы — это веб-карта, с помощью которой можно получить данные о результатах выборов с 2012 по 2022 годы в Москве с максимальной детальностью — вплоть до участковых избирательных комиссий. Информация представлена по трем типам выборов: выборы Мэра Москвы, выборы в Государственную Думу Российской Федерации и выборы Президента Российской Федерации. На веб-карте представлены несколько показателей: преимущество победителя, явка и процент недействительных бюллетеней. Для любого типа выборов созданы интерактивные панели, которые предоставляют конкретную информацию по процентам голосов основных кандидатов или партий на выборах, а также в показателях явки и процента недействительных бюллетеней представлена интерактивная панель динамики соответствующих показателей.
Продукт сделан с помощью инструментов React и leaflet, написан на языке JavaScript.
В репозитории на Github представлены обработанные электоральные данные, которые непосредственно используются для визуализации на карте.
Ссылка на карту: https://terracodingzavr.github.io/MoscowElectionwebmap/
